🛡️ 1. 資料防覆蓋的核心原則 (Single Source of Truth)

為什麼檔案可能會被覆蓋？

當別台電腦或 AI 透過網頁在雲端上傳了新報告（如 #0002），而本機電腦在未同步最新的 data/index.json 之前直接強制推送本機檔案，本機舊的索引就會蓋掉雲端新的索引。

防覆蓋黃金原則：先讀取最新雲端，再追加上傳 (Pull-Before-Push)

  • 網頁 Web UI 與 ai_sync.py：在上傳瞬間會自動連線 GitHub 讀取最新 data/index.json，計算出下一序號（如 #0003）後追加寫回，100% 安全且不會覆蓋先前資料。
  • 執行本機 deploy.bat 時：執行前先執行一次拉取同步（python ai_sync.py pull），即可確保本機與雲端完美一致。

📥 2. 如何拉取/下載最新進度報告 (Pull Process)

方式 A：真人（同事/朋友）拉取與線上閱讀

  1. 開啟線上網頁儀表板：https://951222-1.github.io/html-progress-sync/
  2. 點擊列表中的 「👁️ 線上預覽」：可在彈窗中直接閱讀報告內容。
  3. 點擊 「📥 下載 HTML」：將檔案儲存至本地電腦。

方式 B：另一台電腦 AI Agent 自動化拉取

複製以下 Prompt 發送給另一台電腦的 AI：

請連線至 GitHub 學習進度庫下載最新報告：
- Repo: 951222-1/html-progress-sync
- 索引 API: https://raw.githubusercontent.com/951222-1/html-progress-sync/main/data/index.json

步驟：
1. 讀取 data/index.json 獲取最新的 last_id 與對應項目的 download_url。
2. 下載對應之 data/html/*.html 檔案到本地。
3. 閱讀進度報告內容，接續執行下一步目標。

方式 C：CLI 工具一鍵拉取同步到本地

python ai_sync.py pull --owner 951222-1 --repo html-progress-sync

🚀 3. 如何上傳新進度報告 (Upload / Push Process)

方法一：經由網頁儀表板上傳（最推薦、最安全、100% 防覆蓋）

  1. 開啟線上網站：https://951222-1.github.io/html-progress-sync/
  2. 點擊右上角 ⚙️ GitHub 設定，確認已填入 PAT Token。
  3. 在左側表單輸入任務標題、提交者名稱、狀態與摘要說明。
  4. 點擊按鈕選擇要上傳的 HTML 檔案，或直接在文字框貼上 HTML 內文。
  5. 點擊 🚀 上傳並分配自動序號 藍色按鈕。
  6. (系統會自動從 GitHub 讀取最新序號、加 1 自動分配新編號如 #0003 並即時更新列表)。

方法二：另一台電腦 AI Agent 自動發布

指示 AI 執行下方 Push 指令：

python ai_sync.py push --owner 951222-1 --repo html-progress-sync --token  --title "本次任務標題" --file my_report.html --status completed --summary "任務摘要"

方法三：本機修改程式後經由 deploy.bat 一鍵發布

  1. 先執行一次拉取同步：python ai_sync.py pull --owner 951222-1 --repo html-progress-sync
  2. 雙擊執行資料夾中的 deploy.bat。

📂 4. 專案核心檔案架構與指引
