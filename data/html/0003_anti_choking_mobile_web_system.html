📱 一、架構革命：從「樹莓派＋ESP32 硬體」進化為「純前端 Web AI」

為了解決原系統需攜帶樹莓派主機、ESP32 鏡頭模組及固定連線的繁瑣限制，本次任務成功將整個系統移植為純手機瀏覽器原生運行的獨立 Web 應用：

  • 免任何外部硬體：直接調用個人智慧型手機 (iPhone / Android) 的鏡頭與麥克風，無須樹莓派或額外感測器。
  • 手機端 GPU/WASM 邊緣運算：導入 Google MediaPipe Tasks Vision WebAssembly/WebGL 加速，在手機端達到 30 FPS 的人臉 478 點與手部 21 關節骨架即時追蹤。
  • HTML5 Web Audio 咳嗽聲學特徵分析：利用 Web Audio API 建立即時頻譜分析器，精準擷取 300Hz~2500Hz 突發咳嗽頻段能量。
