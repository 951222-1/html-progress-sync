任務目標

將體感彈弓遊戲的發射判定從「雙手併攏拉弓、張手發射」改為適合長輩操作的流程:雙手併攏舉高過肩 → 往下拉弓 → 續力 3 秒自動發射,同步更新動作教學引導(三欄圖卡 + 插圖小人),並解決實測中判定不穩定的問題。

完成內容

1. 發射判定全面改版(slingshotGame.js)

  • 移除舊觸發:張手發射、雙手分開發射、手離開畫面誤射。
  • 新狀態流:IDLE →(併攏+肩上)→ READY →(拉到肩下 45px)→ PULLING → 續力 3 秒自動發射。
  • 新增姿勢偵測:由 pose landmarks 11/12 取得肩膀位置與肩寬。
  • 蓄力以真實時間差累計(dt 上限 100ms 防切頁暴衝),發射後自動回 IDLE 防連發。

2. 關鍵 Bug 修復

  • READY/PULLING 條件矛盾:原「抓住需肩上、進拉弓需肩下」永遠不可能同時成立,導致正式遊戲無法射擊;修正為抓住後下拉不再要求肩上。
  • 教學第 3 步蓄力被重複加算(3 秒變 1.5 秒):統一由 PULLING 分支處理。

3. 穩定性強化(五道機制)

  • 指數平滑(手部 0.45 / 肩線 0.3)過濾每幀抖動。
  • 肩線記憶 2 秒:pose 短暫抓不到肩不跌回 fallback。
  • 防抖計數:併攏連續 3 幀、進拉弓連續 4 幀才切換狀態。
  • 寬限時制:拉弓中手遺失 <0.6s 沿用最後位置;手微分 <0.25s 不中斷蓄力。
  • Fallback 加強:單手可玩;完全沒手時改用 pose 手腕(visibility 門檻 0.35→0.25)。

4. 長輩友善 UI(gameRenderer.js / main.js)

  • 水果極簡化:移除光環外框、底色圓、漸層陰影,只留放大 emoji(r×2.1)+ 細枝梗;水果本體加大(radius 上限 30→36)。
  • 瞄準提示改為整顆放大脈動(不再靠發光框)。
  • 教學木牌改為三欄圖卡式引導:數字徽章、當前步驟高亮、完成打勾、純 canvas 繪製的示意小人(舉手過肩/併攏下拉/續力碼錶)與虛線箭頭。
  • 小人插圖經三次截圖迭代修正:手臂雙層描邊、舉手避開頭部、下拉手位於胸前。
  • 所有文案同步(教學牌、提示卡、副標):「併攏舉高過肩 → 往下拉弓 → 續力 3 秒發射」。
